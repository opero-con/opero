# Standard ToDo views replace Flow Hub

- **Status:** Accepted

Use the standard ToDo list and form, ToDo Explorer, and existing ToDo reports.
Retire Flow Hub because it duplicates the ToDo workflow. Remove its page,
navigation links, and exclusive APIs while retaining shared report helpers and
ToDo customization, assignment, permissions, and lifecycle behavior.

A migration removes the installed pages and their workspace links without deleting
ToDo records. Existing Flow Hub bookmarks no longer resolve; users can open
ToDo or My ToDos from Approvals instead. Do not introduce a replacement dashboard.
